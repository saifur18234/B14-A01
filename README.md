# 🚀 DevConf 2026

A responsive developer conference landing page built from the DevConf
2026 design. The project presents a modern conference website with a
navigation bar, hero section, speaker profiles, pricing plans,
conference schedule, and footer.

## 🌐 Live Demo

**Live Website:** https://saifur18234.github.io/B14-A01/

**Repository:** https://github.com/saifur18234/B14-A01

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome 6.7.2 (CDN)

## ✨ Main Features

- Responsive navigation bar with conference menu links
- Hero section with "Code. Connect. Create" heading
- Developer conference introduction and registration CTA
- Speaker section with four speaker cards
- Three pricing plans: Standard, Pro, and Team
- Featured Pro pricing card
- Three-day conference schedule
- Social media icons in the footer
- Responsive layout for different screen sizes

## 💻 Run Locally

1.  Clone the repository:

```bash
git clone https://github.com/saifur18234/B14-A01.git
```

2.  Open the project folder:

```bash
cd B14-A01
```

3.  Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better
local development experience.
